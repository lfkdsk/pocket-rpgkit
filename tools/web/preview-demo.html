Preview protocol demo

Paste an rpgkit-project/v1 document, load it into the host over postMessage, start at a tile, and read the running state back. The protocol is rpgkit-preview/v1; see docs/protocols.md.






  
  
The host page (preview/) runs the real engine
  on the pasted document. It answers only the origin configured with
  ?preview-origin= (same-origin always allowed).
